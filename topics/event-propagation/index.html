What does ev.stopPropagation() do?

A click is an event. When you click a nested element, the browser can deliver that event to the element and its ancestors. This journey is called event propagation.

What to notice

  • Capture: the event travels from outer ancestors toward the clicked element.
  • Target: the event reaches the element that was clicked.
  • Bubbling: after the target, the event travels back up through ancestors. Click events bubble by default.
  • event.target is the original clicked element; event.currentTarget is the element whose listener is running now.

Calling ev.stopPropagation() stops the event from continuing to other elements in its path. It does not undo listeners that already ran, and it does not stop other listeners on the same element. It also does not cancel a browser action; ev.preventDefault() is for that.

In OWL, an event handler receives the event as ev, so you can call ev.stopPropagation() there too.
